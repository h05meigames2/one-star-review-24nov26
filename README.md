A single deadpan one-star review of sleep — the everyday essential everyone
relies on and nobody can return. One line, one joke, no winking: it takes
eight hours every night, gives back the same exhaustion, and cannot be
cancelled.

## Run it

```sh
python3 main.py
```

This writes the review line to `entry.txt` inside the directory given by
`MAKEFUN_OUTPUT_DIR` (defaults to `/output`), with no trailing newline.
